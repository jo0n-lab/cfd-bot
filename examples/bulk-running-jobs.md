# 실행 작업 전체 선택·중단

- Telegram: `/queue` → 실행 작업 선택·일괄 중단 → 전체 선택 → 선택 중단 → 확인.
- GUI: 작업 큐의 실행 중 목록 → 전체 선택 → 선택 작업 중단 → 확인.
- Web: 작업 큐의 실행 중 목록 → 전체 선택 → 선택 중단 → 확인.

확인한 작업 ID만 중단하며, 이미 종료된 작업은 건너뛴다. 새로 시작된 작업은 자동으로
선택에 추가하지 않는다. 대기 작업의 전체 취소와 자동 시작 일시 정지는 별도 버튼이다.

대기 작업은 Web의 TCB/legacy-1 등 각 대기열 카드, GUI의 대기열별 탭, Telegram에서
선택한 대기열 안에서 전체 선택·해제·취소한다. 다른 대기열의 선택에는 영향을 주지 않는다.
