# 티켓 선택 삭제

Telegram `/tickets`, GUI와 web 티켓 목록에서 선택 후 삭제한다.
확인 화면에는 삭제 가능한 티켓과 보호되는 티켓의 개수·이유가 표시된다.

| 상황 | 처리 |
|---|---|
| 대기열 이름만 지정한 미접수 티켓 | 삭제 가능 |
| 실행·대기 작업이 없는 매크로 | 소유 child와 함께 삭제 가능 |
| 비활성 매크로의 child 한 개 선택 | 단독 삭제 가능, 부모 목록에서도 제거 |
| 부모 파일이 없거나 부모 목록에서 빠진 비활성 child | 삭제 가능 |
| 큐에 접수·대기 중, 실행·후처리·중단 처리 중 | 보호 |
| 다른 child가 실행·대기 중인 매크로의 완료 child | 보호 |
| 전체 선택에 실행 중 티켓과 비활성 티켓이 섞임 | 보호 항목을 제외한 삭제 가능 목록만 확인 |

확인 후 작업이 시작되면 삭제를 거절한다. 케이스 폴더, 계산 결과와 작업 기록은 유지된다.
